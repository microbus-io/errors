# CLAUDE.md

## Commits

- **Do not commit without explicit approval.** Make changes in the working tree and wait for the user to explicitly
  approve a commit. Approval of one commit does not extend to later ones. This also applies to amending, squashing,
  rebasing and anything else that creates or rewrites commits.
- **Do not add a co-author line to commit messages.** Never add a `Co-Authored-By:` trailer, or any other AI
  attribution, to a commit.
